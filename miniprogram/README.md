# Kanby 微信小程序

个人主体的小程序客户端：微信登录并绑定已有 Kanby 账号、项目切换、轮到我、
卡片详情、评论、验收清单和显式验收。原生 WXML/WXSS/JavaScript，不使用 web-view。

本次交付是源码和本地验证。尚无真实 AppID/Secret，未进行微信真机登录、平台
编译审核、备案、发布或通知跳转联调。`touristappid` 只是开发工具占位值，不能登录。

## 注册与配置

1. 在 https://mp.weixin.qq.com 注册小程序，选择个人主体。按后台要求完成实名、
   认证、类目、隐私指引和小程序备案；Kanby 的任务协作功能能否归入个人可选类目，
   以平台实际审核为准。费用和最新政策以后台为准，本仓库不承诺审核结果。
2. 用微信开发者工具导入本目录，将 `project.config.json` 的 `appid` 改为你的 AppID。
   AppID 是公开标识，AppSecret 永远不能放进小程序代码、Git 或聊天中。
3. Worker 端设置 `WEIXIN_MINI_APP_ID` 和 secret `WEIXIN_MINI_APP_SECRET`。
   本地开发使用 `.dev.vars`；仓库 `.env` 仅作为你的部署工具输入，不会自动成为
   Worker 运行时绑定。不要把根目录 `.env` 复制到此目录。
4. 后端先备份 D1，再通过现有部署流程应用 `drizzle/0020_weixin_mini.sql`；
   部署包含 `/api/mini/*`、`/mini` 的 Worker。当前对话没有执行生产迁移/部署。
   0020 只添加四张 mini 表和索引，保留所有用户、项目、任务及 iLink 绑定。
5. `config.js` 中的 `origin` 指向后端 HTTPS 域名，默认 `https://kanby.dev`。
   将同一域名添加为小程序的 request 合法域名；核实后台的备案、证书和访问要求。
   现有海外 Worker/kanby.dev 尚未验证能满足该配置。不要依赖开发工具“关闭域名
   校验”选项作为发布方案；必要时单独准备合规的 API 域名和部署方案。
6. `/api/mini/*` 使用独立 bearer 会话，不需要向原来的网页接口开放 CORS。
   `CF-Connecting-IP` 限流键要求入口由 Cloudflare 提供可信客户端 IP；其他反向
   代理部署必须设置可信 IP 来源。缺失时共享 unknown 桶，默认每分钟 10 次登录。

## 首次绑定

- 在小程序点击“微信登录”。后端经微信验证 code 后返回五分钟有效的绑定码。
- 在你已登录 GitHub 的 Kanby 网页打开 `https://kanby.dev/mini`，粘贴你自己小程序
  的绑定码，核对当前账号并确认。绑定要求最近 15 分钟内的 GitHub 登录。
- 返回小程序再次登录。微信身份映射到原账号，不新建用户、不自动加入组织。
- 同一 AppID 下每个微信/每个 Kanby 用户只能绑定一个对应账号，换绑先在网页解绑。
- 微信通知/iLink 与小程序登录是独立绑定，不共享 OpenID 或机器人凭证。

## 使用和安全边界

小程序会话有效期七天，存入本机微信 storage；服务器只存 token 哈希。最多保留
五个会话；退出撤销当前会话，网页解绑撤销全部会话。浏览器 Cookie 和 Agent Token
不能用于小程序接口；小程序 token 不能用于浏览器或 Agent 接口。

每次请求检查当前项目成员权限。评论按真实用户记录；清单更新采用双版本检查。
“验收完成”须用户明确确认，且任务为开发中、清单全部勾选，卡片版本未发生变化。
版本冲突时刷新再操作，不覆盖已有修改；发送失败的评论保留在输入框。

详情描述以纯文本显示，支持复制。附件/GitHub 链接可复制到浏览器，附件仍需浏览器
登录且有项目权限；不把小程序 token 拼到链接里。页面仅展示有权限的项目数据，
不能在小程序搜索中索引。

入口参数支持 `pages/index/index?projectId=<项目ID>&taskId=<任务ID或KANBY-编号>`，
登录前后保留目标。尚未接通从现有 iLink 通知直接唤起小程序的方式；原来的网页
通知链接保持原样。URL Link/Scheme、开放标签和消息卡片的主体权限必须分别验证，
不要把这个路由参数支持描述成“微信通知已直达小程序”。

## 本地检查与发布前验收

在仓库根目录执行 `npm ci`、`npm run gauntlet`。专门测试为
`npm run test:mini`。客户端逻辑通过 Node VM 执行，微信 API 是边界替身；
这不等于微信开发者工具编译或真机渲染通过。

注册后还需执行：

- 使用真实 AppID 编译和预览；检查 WXML、样式、中文长文和手机安全区域。
- 真实微信登录 → 网页绑定 → 再登录 → 项目列表；另一个微信不能接管原账号。
- 跨项目访问拒绝；退出、解绑、过期、移除项目成员后访问拒绝。
- 轮到我 → 卡片详情 → 评论 → 勾选清单 → 明确验收，网页核对活动和状态。
- 网页同时修改卡片时小程序提示冲突；弱网、401、限流时可以恢复。
- 直接路径启动并登录，仍打开指定卡片；验证通知入口后再变更通知内容。
- 完成隐私声明、主体/类目/域名配置和平台审核，才发布正式版。

回退时先回退 Worker 并停用小程序版本；四张 mini 表可保留以便再次上线。
如需永久删除此功能数据，先确认备份，再按 sessions → pairs → identities → limits
顺序删除；不要删除原有业务表。测试包含本地删除新增表后原任务仍存在的演练。
