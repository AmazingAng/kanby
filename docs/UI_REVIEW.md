# Kanby UI review · 2026-09-14

## 结论

保留米白、墨色与荧光绿的识别度，优先重整信息层级与操作反馈。主要问题集中在看板和手机适配，无需推翻整套视觉设计。

## 本轮已调整

| 问题                                                    | 调整                                                                                                                     |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 看板日期写死为第 36 周，“本周进度”实际统计项目全部任务  | 移除固定日期，正式项目显示项目名称；概览明确显示任务总数、进行中和已完成数，进度标注为项目完成度                         |
| 卡片存在多层彩色面板，归档按钮始终抢占注意力            | 统一卡片底色、缩小圆角、简化验收与子任务进度；保留父子任务标签和侧边色条；鼠标设备悬停或键盘聚焦时显示归档，触屏始终可用 |
| Markdown 的固定白色渐变覆盖单行描述，并与彩色卡片不匹配 | 保留限高摘录，移除覆盖内容的渐变                                                                                         |
| 手机无法直接筛选负责人，搜索无结果和空看板混在一起      | 新增负责人选择、搜索清除、结果数量与重置；无匹配任务单独提示                                                             |
| 手机列导航缺少当前列反馈                                | 分段导航显示选中状态，并跟随横向滚动更新；尊重减少动态效果偏好                                                           |
| 任务编辑器直接显示 `building` 等内部状态值              | 显示中文状态，并为状态、标签、新任务标题补齐可访问名称                                                                   |
| 首页手机端网格撑宽，正文与预览被页面裁切                | 明确单列网格的收缩约束，预览在自身容器内横向滚动；增加中文标题行高                                                       |
| 首页未清楚呈现产品的 Agent 协作定位                     | 更新主文案与功能说明，突出人与 Agent 共用任务和活动记录                                                                  |
| 项目页重复展示已交付数量                                | 移除底部重复统计，让项目入口更集中                                                                                       |
| 设置页章节较长、侧栏滚动后消失                          | 新增四个章节锚点，桌面侧栏固定在可视区域                                                                                 |
| 次要文字对比度偏低，手机导航图标缺少名称                | 调整次要文字颜色，补充导航名称、当前页状态与键盘焦点样式                                                                 |

## 验证

- 148 项现有测试通过；TypeScript、lint、生产构建通过。
- Chromium 实际验证搜索、多负责人筛选、清除与重置、无结果状态、新建、编辑自动保存、跨列拖拽。
- 手机触屏环境验证列跳转、滚动选中状态、负责人筛选、归档可见性与归档操作。
- 检查 320、390、768、1024、1440px 看板布局；首页额外检查正文和预览的元素边界，避免仅检查页面宽度漏掉被裁切的内容。
- 项目页、设置页使用浏览器内的本地模拟 API 数据验证布局与章节导航；未执行真实登录、仓库配置或 Token 操作。
- 截图与本次浏览器验证脚本位于 `outputs/ui-review/`（本地生成文件，不纳入 Git）。脚本使用本机 Playwright 运行时与 `localhost:3001`。
